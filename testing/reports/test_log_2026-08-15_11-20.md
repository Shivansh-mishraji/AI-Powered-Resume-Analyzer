### Partial score

**Test file:** `test_score_calculator.py`
**Status:** FAILED

**What the error said:**
```
AssertionError: assert 66 == 67
  where 66 = calculate_match_score(['Python', 'FastAPI'], ['Python', 'FastAPI', 'SQL'])
```

**Root Cause:** Score used `int(matched / total * 100)` which floors the result. `2/3 * 100 = 66.6` became `66`, but the test expected the rounded value `67`.

**Fix Applied:** Changed `int(...)` to `round(...)` in `score_calculator.py`.

**Fixed by:** Shivansh Mishra on Aug 15, 2026.

---

### Empty jd returns zero

**Test file:** `test_score_calculator.py`
**Status:** FAILED

**What the error said:**
```
ZeroDivisionError: division by zero
  score_calculator.py, line 14
```

**Root Cause:** No guard clause — when the job description had no skills, the function tried to divide the match count by zero total skills.

**Fix Applied:** Added `if not jd_skills: return 0, [], []` at the top of the function.

**Fixed by:** Shivansh Mishra on Aug 15, 2026.

### Case insensitive matching

**Test file:** `test_score_calculator.py`
**Status:** FAILED

**What the error said:**
```
AssertionError: assert 0 == 100
  'python' in resume not matching 'Python' in job description
```

**Root Cause:** String comparison was case-sensitive. A resume with "python" (lowercase) did not match the job description's "Python" (title case).

**Fix Applied:** Added `.lower()` normalization to both skill sets before comparison in `score_calculator.py`.

**Fixed by:** Shivansh Mishra on Aug 15, 2026.

### Total jd skills count

**Test file:** `test_score_calculator.py`
**Status:** FAILED

**What the error said:**
```
AssertionError: assert 0 == 3
  Function returned empty list for total_jd_skills
```

**Root Cause:** The function was not returning the full list of JD skills in the response — only the matched ones. The test expected all skills from the job description to be included in the output.

**Fix Applied:** Updated return value to include `jd_skills` (all extracted JD skills, not just matched ones).

**Fixed by:** Shivansh Mishra on Aug 15, 2026.

### No duplicate skills

**Test file:** `test_skill_extractor.py`
**Status:** FAILED

**What the error said:**
```
AssertionError: assert ['Python', 'Python', 'SQL'] == ['Python', 'SQL']
  Duplicate skills returned in the list
```

**Root Cause:** `skill_extractor.py` appended each match to a list without checking if it already existed. If "Python" appeared twice in a resume, it was returned twice.

**Fix Applied:** Wrapped result in `list(set(...))` then sorted alphabetically.

**Fixed by:** Harshvardhan Sisodiya on Aug 15, 2026.

### Empty text returns empty list

**Test file:** `test_skill_extractor.py`
**Status:** FAILED

**What the error said:**
```
TypeError: 'NoneType' object is not iterable
  skill_extractor.py, line 8
```

**Root Cause:** The function tried to iterate over the input text even when it was `None` or an empty string, causing a crash.

**Fix Applied:** Added `if not text: return []` guard at the very start of the function.

**Fixed by:** Harshvardhan Sisodiya on Aug 15, 2026.
