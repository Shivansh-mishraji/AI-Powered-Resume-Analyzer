### None returns empty list

**Test file:** `test_skill_extractor.py`
**Status:** FAILED

**What the error said:**
```
TypeError: argument of type 'NoneType' is not iterable
  skill_extractor.py, line 12: if skill.lower() in text.lower()
```

**Root Cause:** The earlier fix guarded against `None` input at the function entry, but the inner loop still passed `None` to a string operation when processing the skills list against the text. A separate path in the code was not covered.

**Fix Applied:** Strengthened the guard — `if not text or not isinstance(text, str): return []`

**Fixed by:** Harshvardhan Sisodiya on Aug 15, 2026.

### Clean text removes special characters

**Test file:** `test_text_cleaner.py`
**Status:** FAILED

**What the error said:**
```
AssertionError: assert 'hello world' == 'hello  world'
  Extra space left where special character was removed
```

**Root Cause:** The regex `re.sub(r'[^a-zA-Z0-9\s\+\#]', '', text)` replaced special characters with nothing, leaving double spaces when a symbol appeared between words (e.g. `"hello, world"` → `"hello  world"`).

**Fix Applied:** Added a second `re.sub(r'\s+', ' ', text).strip()` pass to collapse multiple spaces into one after removal.

**Fixed by:** Sujeet Kannaujiya on Aug 15, 2026.
